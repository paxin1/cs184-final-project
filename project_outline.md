# Snow footprints

#### Real-time graphics project with demo

#### Key Concepts

- Real-time snow deformation

-  Mesh topology of snow-covered ground

- Footprint walking simulation - snow recesses on contact with mesh

- Physics engine for snowfall, footprint contact

- Snowfall generator

- Simulation of snowfall on mesh topology
